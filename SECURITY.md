# Security

This repository is a documentation-only public showcase.

The production application, source code, credentials, customer data, deployment configuration, and internal environment documentation are intentionally kept in private repositories.

## Sensitive information

Do not commit:

- API keys
- access tokens
- environment files
- database credentials
- service-role credentials
- webhook secrets
- private keys
- customer information
- production logs
- internal admin identifiers

If sensitive information is ever committed accidentally, it should be treated as compromised and rotated immediately.
