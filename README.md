# ExposeDraft — Public Project Showcase

> **Portfolio showcase only.** The production source repository is private and is not mirrored here.

## Overview

**ExposeDraft** is an AI-powered real estate workflow platform designed for German real estate professionals.

The product is built around a simple goal: reduce repetitive manual work between collecting property information and producing polished, client-ready marketing output.

**Live product:** https://exposedraft.com

## Problem

Creating and maintaining real estate marketing material often involves repeated manual steps: collecting property data, organizing images, writing descriptions, preparing documents, and keeping information consistent across the workflow.

ExposeDraft brings those steps into one structured application and adds AI where it can save meaningful time.

## Selected capabilities

- **AI-assisted copy** for property descriptions and listing content
- **Image analysis and media workflows**
- **Structured property management**
- **PDF exposé generation**
- **Authentication and account workflows**
- **Subscription and billing integration**
- **Privacy-conscious product analytics**
- **German / English application support**
